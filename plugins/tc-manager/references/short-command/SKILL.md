name: tc-manager
description: 기존 TC 정리·신규 TC 작성·테스트 준비를 자연어로 요청하는 단축 명령.
---

사용자 요청: $ARGUMENTS

Skill 도구로 `tc-manager:manage`를 호출하고 요청·첨부·이전 결과·검토 의견을 그대로 전달한다. 인자가 없으면 세 업무와 예시를 안내한다. 과거 TC나 폴더를 임의로 선택하지 않는다.
해당 Skill이 없으면 tc-manager 1.1 이상 설치/활성화가 필요하다고 안내한다. 이전 create 명령으로 몰아서 처리하지 않는다. 이 파일은 프로젝트 단축 호출이고 본체는 팀에 배포할 플러그인이다.
